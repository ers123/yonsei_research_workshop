# Reference Notes

이 워크숍의 DSB 논문 초안은 교수님이 공유한 연구자료를 참고해 만든 데모입니다.

다만 이 폴더는 공개/배포 가능한 워크숍 패키지이므로 원자료 자체는 포함하지 않습니다. 원자료에는 논문 PDF, 발표자료, 앱/특허 문서, 데이터 요약, 인터뷰 및 참여자 단위 자료가 포함될 수 있습니다.

## 공개 패키지에 포함하지 않는 자료

- raw interview / transcript
- participant-level dataset
- raw CSV row
- 실명 또는 식별 가능한 파일명
- quote approval 전 원문
- private link
- IRB/동의 관련 민감 자료

## 공개 패키지에 포함하는 자료

- 연구자가 검토할 수 있는 초안
- 자료 목록과 근거 연결표
- 아직 하면 안 되는 주장 목록
- risk/review memo
- figure/table plan
- AI-use log prompt

## 워크숍에서 설명할 문장

```text
이 데모 초안은 교수님이 공유한 연구자료를 바탕으로 만들었습니다. 다만 워크숍 폴더에는 원자료를 넣지 않고, 공개 가능한 초안 패키지와 근거/위험/검토 기록만 남겼습니다.
```
