# TOC to Paragraph Units

상세 목차를 만들었다고 해서 그 항목을 모두 heading으로 써야 하는 것은 아닙니다.

장문 논문에서는 목차의 세부 항목을 실제 본문 문단 단위로 바꾸는 작업이 중요합니다.

## 나쁜 단위

```text
2장 이론적 배경을 써줘.
```

너무 큽니다. AI가 일반론으로 채울 가능성이 높습니다.

```text
2.1 자기조절 이론을 길게 설명해줘.
```

아직 큽니다. 정의, 선행연구 흐름, 본 연구와의 연결, 한계를 분리해야 합니다.

## 좋은 단위

```text
Unit 2.1.1:
자기조절 이론이 본 연구에서 왜 필요한지 1개 문단으로 설명한다.
사용 자료: literature-flow-report A, benchmark paper 2
금지 주장: 효과 입증, 통계적 유의성
```

## 변환 프롬프트

```text
아래 상세 목차를 실제 본문 작성 unit으로 바꿔 주세요.

규칙:
- 각 unit은 1개 중심 기능만 가져야 합니다.
- unit 하나는 1문단 또는 최대 2문단으로 작성 가능해야 합니다.
- 모든 unit에 사용할 자료를 연결하세요.
- 자료가 없는 unit은 "자료 보강 필요"로 표시하세요.
- heading으로 쓸 항목과 본문 문단으로 녹일 항목을 구분하세요.

출력:
| Unit ID | 장/절 위치 | heading 여부 | 문단 기능 | 사용할 자료 | 금지 주장 | 예상 길이 |
|---|---|---|---|---|---|---|

예상 길이:
- short: 4-6문장
- medium: 7-10문장
- long: 2문단
```

## Unit 유형

| 유형 | 목적 |
|---|---|
| definition | 핵심 개념 정의 |
| literature-flow | 선행연구 흐름 설명 |
| gap | 기존 연구의 한계 또는 빈틈 |
| bridge | 앞 절과 다음 절 연결 |
| method-rationale | 방법 선택 이유 |
| finding-summary | 자료에서 나온 결과 요약 |
| caveat | 해석 한계 명시 |
| transition | 다음 논의로 이동 |

## 분량 확장 방법

분량이 부족하면 새 내용을 붙이지 말고 unit을 나눕니다.

예:

```text
Unit 2.1 자기조절 이론
  -> 2.1.1 핵심 개념 정의
  -> 2.1.2 디자인 연구에서의 활용 흐름
  -> 2.1.3 본 연구 자료와의 연결
  -> 2.1.4 해석상 한계
```

이렇게 하면 길이는 늘어나지만 근거 없는 내용은 줄어듭니다.
