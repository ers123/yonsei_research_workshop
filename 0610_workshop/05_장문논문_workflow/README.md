# 05. 장문논문 Workflow

이 폴더는 짧은 논문 초안보다 긴 학위논문이나 장문 원고를 쓰고 싶을 때 사용합니다.

핵심은 다음 한 줄입니다.

> 먼저 학습시키고, 바로 답하게 하지 말고, 목차를 세밀하게 만든 뒤, 한 section 또는 한 문단 단위로만 생성한다.

## 왜 별도 workflow가 필요한가

긴 원고에서 가장 흔한 실패는 AI에게 한 번에 너무 큰 단위를 맡기는 것입니다.

피해야 할 요청:

- "논문 전체 써줘"
- "서론 전체 써줘"
- "2장 이론적 배경 길게 써줘"
- "분량이 부족하니까 더 늘려줘"

이런 요청은 근거 없는 문헌, 반복 문장, 과장된 일반화, citation gap을 만들기 쉽습니다.

## 권장 순서

1. 자료와 문헌 흐름 보고서를 넣되, 답하지 말고 학습만 하게 한다.
2. 모든 자료를 넣은 뒤 제목/주제 후보 2-3개만 받는다.
3. 사람이 후보를 고른다.
4. 5장 체계의 상세 목차를 만든다.
5. 목차의 하위 항목을 문단 작성 unit으로 바꾼다.
6. 한 번에 한 unit만 작성한다.
7. 각 unit마다 citation/reference status를 확인한다.
8. 필요한 경우 unit을 더 잘게 나누어 분량을 늘린다.
9. 장 전체를 합친 뒤 연결, 중복, 인용, 위험을 검토한다.

## 파일 설명

| 파일 | 용도 |
|---|---|
| `training_first_protocol.md` | 자료를 먼저 학습시키고 기다리게 하는 방법 |
| `toc_to_paragraph_units.md` | 상세 목차를 실제 문단 작성 단위로 바꾸는 방법 |
| `section_by_section_prompt_chain.md` | 한 unit씩 작성하고 검토하는 prompt chain |


```text
큰 요청을 작게 나누고,
작은 단위마다 근거를 확인하고,
사람이 gate를 통과시킨다.
```
