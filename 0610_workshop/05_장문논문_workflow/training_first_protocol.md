# Training-First Protocol

장문 논문 작성에서 첫 단계는 생성이 아니라 학습입니다.

AI에게 자료를 넣자마자 요약, 목차, 본문을 쓰게 하면 자료의 미묘한 흐름을 놓치고 일반적인 글을 만들 가능성이 큽니다. 먼저 자료를 읽게 하고, "아직 답하지 말라"는 상태를 유지합니다.

## 준비물

- 연구계획서 또는 RQ memo
- 문헌 흐름 정리본
- 핵심 논문 요약
- 지도교수 피드백
- 데이터/자료 설명서
- 금지 주장 목록

## Step 1. 학습 모드 선언

```text
지금부터 자료를 여러 번에 나누어 제공하겠습니다.

아직 어떤 산출물도 만들지 마세요.
목차, 제목, 본문, 요약, 평가를 생성하지 마세요.
각 자료를 읽고 학습만 하세요.

각 자료를 읽은 뒤에는 다음처럼만 답하세요.

"검토 완료. 아직 생성하지 않음."

학습 관점:
- 연구주제
- 핵심 개념
- 선행연구 흐름
- 자료 간 연결
- 근거가 강한 주장과 약한 주장
- 학위논문에서 다룰 수 있는 범위
```

## Step 2. 자료를 묶음 단위로 넣기

```text
자료 묶음 1: [문헌 흐름 정리본 이름]

아래 자료를 학습만 하세요.
아직 제목, 목차, 본문을 만들지 마세요.

[자료 내용]
```

자료가 끝날 때마다 AI가 길게 답하면 다시 멈춥니다.

```text
아직 생성하지 마세요.
다음 자료를 기다리세요.
```

## Step 3. 전체 학습 확인

모든 자료를 넣은 뒤에만 실행합니다.

```text
지금까지 제공한 자료를 기준으로, 아직 본문은 쓰지 말고 학습 상태만 점검해 주세요.

출력:
1. 반복적으로 등장한 핵심 개념
2. 문헌 흐름의 큰 방향
3. 자료가 강하게 뒷받침하는 주장
4. 자료가 약하거나 누락된 부분
5. 사람이 먼저 결정해야 할 부분

아직 제목, 목차, 본문은 만들지 마세요.
```

## Step 4. 제목 후보는 그 다음

```text
이제 지금까지 학습한 자료만 바탕으로 장문 논문 제목 또는 주제 후보를 2-3개 제안해 주세요.

각 후보마다:
- 잠정 제목
- 핵심 연구질문
- 사용할 수 있는 자료
- 장점
- 위험
- 추가 확인 필요
를 표로 정리하세요.

아직 본문은 쓰지 마세요.
```

## 흔한 오류

| 오류 | 수정 |
|---|---|
| 자료 1개 넣고 바로 목차 요청 | 모든 자료를 학습시킨 뒤 목차 요청 |
| AI가 긴 요약을 시작함 | "검토만 하고 기다리라"고 재지시 |
| 제목 후보가 자료 밖으로 나감 | "제공 자료만 사용"으로 재생성 |
| 목차가 너무 일반적임 | 자료명과 evidence status를 각 항목에 붙이게 함 |
