# Thread Return Template

각 worker thread는 이 형식으로 하나의 반환 파일을 작성합니다.

```markdown
# [Worker Role] Return

## 핵심 3줄

1.
2.
3.

## 사용한 입력

-

## 허용 가능한 주장 또는 산출물

| Item | Evidence | Status |
|---|---|---|
|  |  | allowed / allowed with caveat |

## 제한해야 할 주장 또는 산출물

| Item | Reason | Status |
|---|---|---|
|  |  | blocked / human-only / needs verification |

## Draft에 반영할 항목

-

## Supervisor Decision Needed

-
```
