# Risk And Review

이 폴더는 초안의 약점과 아직 사람의 승인이 필요한 부분을 모은 것입니다.

| 파일 | 역할 |
|---|---|
| `draft-risk-report.md` | unsupported claim, privacy, translation, statistics risk |
| `review-report.md` | 초안 비평과 rewrite 요구사항 |
| `peer-review-risk-memo-v0.2.md` | 동료심사 관점에서 예상되는 주요 리스크 |
| `draft-package.md` | 연구자 검토용 패키지 요약 |

워크숍에서 이 폴더를 보여주는 이유는 AI 초안의 한계를 숨기지 않기 위해서입니다.

```text
좋은 AI 활용은 초안을 빨리 만드는 것이 아니라, AI가 만든 초안이 어디서 약하고 무엇을 아직 주장하면 안 되는지 같이 남기는 것입니다.
```
