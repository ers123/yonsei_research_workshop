# Final Draft Examples

이 폴더에는 워크숍에서 먼저 보여줄 최종 산출물 예시를 모았습니다.

| 파일 | 용도 |
|---|---|
| `manuscript-draft-ko-v0.2.md` | 한국어 논문 초안 |
| `manuscript-draft-en-v0.2.md` | 영어 논문 초안 |
| `apa7-visual-thread-paper-draft.docx` | 그림/표 포함 APA-like / APA 7-style Word 시연 예시 |
| `compact-thread-expanded-draft.md` | Codex compact 5-worker run으로 확장한 초안 |
| `final-threaded-package.md` | Codex thread 운영 결과 요약 |
| `figures/` | 승인된 데모용 figure 이미지 |

주의: 이 파일들은 워크숍과 연구자 검토용입니다. 외부 배포나 투고 가능 상태를 의미하지 않습니다.

`apa7-visual-thread-paper-draft.docx`는 APA 7-style 문서 구조와 figure/table placement를 보여주는 시연용입니다. 실제 투고용 APA final manuscript로 설명하면 안 됩니다.

참고문헌, conference paper metadata, internal technical disclosure, 특허/앱 관련 서술은 human verification이 끝나기 전까지 `needs verification` 상태로 다뤄야 합니다.

이 폴더는 원자료 없이 sanitized package와 검토 가능한 산출물을 보여줍니다. 즉, 실제 원자료에서 새 분석을 실행했다는 시연이 아니라, 정리된 자료와 위험 경계를 바탕으로 초안 패키지를 구성한 예시입니다.
